🔐 المصادقة — OAuth2 & JWT

الحصول على رمز الوصول للوصول لجميع نقاط النهاية

POST /v3/auth/token الحصول على JWT Token

أرسل بيانات اعتمادك للحصول على رمز وصول صالح لمدة 24 ساعة.

POST https://api.sr-coresync.com/v3/auth/token Content-Type: application/json { "client_id": "YOUR_CLIENT_ID", "client_secret": "YOUR_CLIENT_SECRET", "grant_type": "client_credentials", "scope": "advisor:read tax:write audit:full" } // Response { "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...", "token_type": "Bearer", "expires_in": 86400, "scope": "advisor:read tax:write audit:full" }
POST /v3/auth/refresh تجديد رمز الوصول
POST https://api.sr-coresync.com/v3/auth/refresh Authorization: Bearer {refresh_token} // Response: نفس بنية /token مع رمز جديد

🧠 API المستشار الذكي

تحليل ضريبي، توصيات استراتيجية، حساب KIA وZelfstandigenaftrek

POST /v3/advisor/analyze تحليل ضريبي واستراتيجي شامل

🔍 API التدقيق الضريبي

مطابقة الفواتير، IFRS، AAOIFI، تصدير حزمة Big-4

POST /v3/audit/run تشغيل مطابقة ضريبية كاملة
POST https://api.sr-coresync.com/v3/audit/run Authorization: Bearer {token} { "records": [ { "invoice_id": "INV-2601", "net": 10000, "vat": 2100, "standard": "IFRS" } ], "export_format": "json", "link_advisor_session": "sess_abc123" } // Response: نتائج مطابقة + ربط تلقائي بتقرير المستشار الذكي { "audit_id": "AUD-2026-001", "findings": 2, "balanced": 18, "advisor_link": "/v3/advisor/report/sess_abc123", "export_url": "https://api.sr-coresync.com/v3/audit/export/AUD-2026-001" }
GET /v3/audit/export/{audit_id} تصدير حزمة تدقيق Big-4
GET https://api.sr-coresync.com/v3/audit/export/AUD-2026-001?format=pdf Authorization: Bearer {token} // يُنزّل ملف PDF/JSON/CSV جاهز للمراجعة بمعايير Big-4
